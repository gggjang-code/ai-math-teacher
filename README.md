# 📐 AI 수학 튜터 (AI Math Teacher)

학생들이 문제를 사진으로 찍어 올리거나 질문하면, 정답을 바로 알려주지 않고 **핵심 개념과 단계별 힌트**로 풀이를 유도하는 Gemini 기반 웹 애플리케이션입니다.

---

## 🚀 실행 방법

### 1. 필수 라이브러리 설치
터미널(PowerShell 또는 명령 프롬프트)을 열고 아래 명령어를 실행합니다:
```bash
pip install -r requirements.txt
```

### 2. 웹앱 실행
```bash
streamlit run app.py
```

### 3. 브라우저 접속
명령어를 실행하면 웹 브라우저(`http://localhost:8501`)가 자동으로 열립니다.
- 왼쪽 사이드바에 [Google AI Studio](https://aistudio.google.com/)에서 무료로 발급받은 **Gemini API Key**를 입력하고 사용하시면 됩니다.
